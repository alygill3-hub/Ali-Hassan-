# 🏧 ATM Simulation System Using Python Flask

A secure and interactive web-based ATM Simulation System developed using **Python Flask**, **HTML**, **CSS**, and **JavaScript**. This project simulates the core functionalities of a real ATM machine and is designed for educational purposes.

---

## 📌 Features

- 🔐 PIN Authentication
- 💰 Balance Inquiry
- ➕ Cash Deposit
- ➖ Cash Withdrawal
- 🔑 Change PIN
- 🚪 Secure Logout
- 🌐 Responsive Web Interface

---

## 🛠 Technologies Used

- HTML5

## 🚀 Installation

### 1. Clone Repository

```bash
git clone https://github.com/your-username/ATM-Simulation-System-Using-Python-Flask.git
```

### 2. Open Project

```bash
cd ATM-Simulation-System-Using-Python-Flask
```

### 3. Install Dependencies

```bash
pip install flask
```

### 4. Run Application

```bash
python app.py
```

### 5. Open Browser

```
http://127.0.0.1:5000
```
